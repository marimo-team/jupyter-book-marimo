# marimo tutorials

These pages are copied into regular Jupyter Book Markdown and executed by
`jupyter-book-marimo` during the build. They are the main regression surface for
the plugin: each page checks that marimo cells render, hydrate, and stay
reactive in the published book.

Start with the intro, then move through the runtime, UI, markdown, plotting,
layout, file-format, dependency, and SQL examples.
