# Reference

Use `jupyter-book-marimo` to write executable marimo cells in MyST pages:

- write cells with `{marimo}`;
- configure page defaults with `{marimo-config}`;
- set directive options with MyST syntax, such as `:echo: true`; and
- use `python`, `sql`, or `markdown` as the cell language.
